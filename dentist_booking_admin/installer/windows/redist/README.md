# Visual C++ Redistributable (x64)

Flutter Windows release builds require the **Microsoft Visual C++ Redistributable** on end-user PCs.

Place this file in this folder (or let `build_release.ps1` download it automatically):

- **File name:** `VC_redist.x64.exe`
- **Official download:** https://aka.ms/vs/17/release/vc_redist.x64.exe

The binary is gitignored. Do not commit it to the repository.
